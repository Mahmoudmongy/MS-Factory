# مدير المصنع V4 — نسخة GitHub

نظام ويب عربي RTL لإدارة نشاط تجاري/مصنع، يعمل كتطبيق متصفح ويمكن تثبيته كتطبيق PWA.

## محتويات الحزمة
- `index.html`: نقطة تشغيل النظام.
- `css/style.css`: التنسيق ودعم الشاشات الصغيرة.
- `js/app.js`: منطق النظام.
- `assets/`: الأيقونات.
- `manifest.json` و`sw.js`: إعدادات PWA والتخزين المؤقت.
- `tests.html`: اختبارات تشغيل أساسية داخل المتصفح.

## التشغيل والرفع
1. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub، وليس ملف ZIP نفسه.
2. من GitHub افتح Settings → Pages.
3. اختر Deploy from a branch، ثم `main` و`/(root)`، واحفظ.
4. افتح رابط GitHub Pages الناتج. يفضل استخدام HTTPS.
5. على Android افتح الرابط في Chrome ثم اختر تثبيت التطبيق / Add to Home screen.

## تشغيل محلي
لأن Service Worker لا يعمل عادةً من `file://`، شغّل مجلد المشروع عبر خادم محلي (مثل Live Server في VS Code أو `python -m http.server 8000`) ثم افتح `http://localhost:8000`.

## التخزين والنسخ الاحتياطي
- البيانات تُحفظ محليًا في `localStorage` على نفس المتصفح والجهاز.
- لا يوجد خادم مركزي أو تسجيل دخول حقيقي أو مزامنة بين الأجهزة في هذه النسخة.
- مسح بيانات المتصفح قد يؤدي إلى فقد البيانات؛ استخدم ميزة النسخ الاحتياطي داخل النظام بانتظام.
- لا تضع بيانات عملاء حقيقية أو بيانات مالية حساسة قبل مراجعة الأمان والنسخ الاحتياطي.

## حدود مهمة تم اكتشافها أثناء المراجعة
- النظام الحالي نسخة محلية/تجريبية، وليس نظامًا متعدد المستخدمين أو Backend متصلًا بـ Supabase.
- بعض الوظائف تعتمد على مكتبات خارجية من CDN؛ لذلك لا يمكن ضمان جميع وظائف PDF/استيراد الملفات عند انقطاع الإنترنت لأول مرة.
- المساعد الذكي يعتمد على بيئة Claude داخلية، وقد لا يعمل عند استضافة الموقع بشكل مستقل.
- تم إصلاح تنزيل CSV وPDF ليستخدما تنزيل المتصفح بدل تكامل `claude.use("downloads")`.
- `tests.html` فحص دخاني (Smoke Test) لسلامة التحميل والبنية الأساسية، ولا يثبت صحة كل القيود المحاسبية أو جميع السيناريوهات.

## الاختبار
بعد النشر افتح `/tests.html`. يجب أن تظهر نتائج الاختبارات بجانب واجهة النظام المضمنة. جرّب أيضًا فتح النظام على هاتف فعلي، وإضافة بيانات تجريبية، ثم تصدير نسخة احتياطية واستعادتها قبل إدخال بيانات فعلية.
